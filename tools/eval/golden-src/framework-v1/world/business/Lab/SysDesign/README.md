# SysDesign

Wren 的系统设计学习项目：按课程章节精读、写笔记，教练（Claude）答疑、出题、点评。每章一个目录。

| 章节 | 目录 | 主题 |
|---|---|---|
| ch-adclick | `ch-adclick/` | 广告点击事件聚合：流处理、event time、watermark、exactly-once |
| ch-chat | `ch-chat/` | 聊天系统：WebSocket、有状态服务、服务发现、在线状态 |
| ch-sharding | `ch-sharding/` | 数据库分片：shard key、一致性哈希 |
| ch-payment | `ch-payment/` | 支付系统：幂等 |
| ch-cap | `ch-cap/` | CAP 定理 |
