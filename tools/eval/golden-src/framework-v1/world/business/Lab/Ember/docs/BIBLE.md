## 1. 定位与基调
- `[定]` 群像游历：每到一处，写当地的人怎么活、怎么选；主角是穿起这些故事的线
- `[定]` 主角很强，但强解决不了大部分麻烦；麻烦多半出在人和规则上，不在打不打得过
- `[定]` 友情是主线之一：岑舟与祁默是旧友，不写成恋人

## 2. 叙事结构
- `[定]` 以绘图为骨架：祁默要绘一部《万界舆图》，每一卷对应一片地域，岑舟一路随行护送
- `[定]` 开篇就在路上；两人的旧事穿插在当下的事件里讲，不单开回忆卷
- `[待定]` 结局（伏笔要先知道终点，优先级高）

## 3. 世界

### 3.1 三界与修为
- `[定]` 三界：沉壤（凡人与低阶修士聚居）、浮屿（悬空群岛，宗门林立）、星阙（最高一界，人少而强）。
  界与界之间靠渡口往来
- `[定]` 修为：养息 → 通脉 → 结珠 → 化形 → 观星 → 踏虚 → 归一，每境分初、中、后三期
- `[定]` 寿元随修为增长，境界越高活得越久（各境具体年数待定）
- `[待定]` 跨界往来的代价

### 3.2 承载与压制
- `[定]` 每一界有承载上限：沉壤最高化形后期，浮屿最高踏虚初期，星阙不设限。
  上界修士进入下界，修为被天衡压到该界的上限，正好卡在上限，不多不少
- `[定]` 被压下去的修为不会消失，离开该界即恢复
- `[定]` 单招上限：一招之力超过所在界的承载，四周空中先浮现冰裂般的「界纹」示警；
  仍强行出手，整个界随之崩塌，界内无人能逃
- `[提议]` 界纹出现到崩塌之间约有十息，给打斗留出收手或抢断的余地
- `[提议]` 界纹人人看得见，是读者也看得懂的危险读数，不用报数值
- `[待定]` 崩塌之后界的残骸会怎样（Claude 建议：化为没有灵气的死地）

### 3.3 天衡
- `[定]` 三界的规则由「天衡」维系；天衡没有意志，像一杆秤
- `[提议]` **天衡是双刃剑**：
  - 枷锁：跨界代价高昂、寿元有上限、下界修为被压
  - 保护：上界强者不能随意下界碾压，各界也不会互相吞并
- `[提议]` 天衡松动的迹象：沉壤的灵气一年比一年薄（补天盟手里的证据）

## 4. 人物

### 4.1 岑舟（主角）
- `[定]` 沉壤渔村出身，如今是星阙公认最强的几人之一
- `[定]` 话少，记仇也记恩；做事先算代价，算完就不犹豫
- `[提议]` 习惯用最小的力气解决问题，不爱出大招

### 4.2 祁默（旧友）
- `[定]` 岑舟的同村旧友，制图师，修为通脉后期；看地形、读古碑、算路线的本事远超常人
- `[定]` 游历的另一个目的：岑舟沿途替祁默寻机缘、提修为。他修为太低，寿元比她短得多，
  不提上去，他会早早老去，走在她前面
- `[提议]` 祁默自己并不急着长寿，更在意舆图画不画得完 → 两人目标的错位留作中段转折

## 5. 补天盟
- `[定]` 上界老修士结成的同盟，行事低调，各界都有人
- `[定]` 动机：天衡在慢慢松动，几百年后各界边界撑不住，会互相吞并，死的人更多
- `[定]` 办法：抽干一整个界的灵脉去补天衡，首选沉壤（修为低，按他们的算法「代价最小」）
- `[定]` 不是坏人，是算账的人：牺牲一界救两界，他们真心觉得对
- `[待定]` 盟中谁能与岑舟一战
