# Session 005 — L1 单链推理「收银台前的急客」

> Wren 答题前请勿阅读本文件。真相与评分点预写于出题时。
> 教学意图：复测 004 的失分技能，即行为/物品的功能分析（组合的用途、动作的目的），换场景防止背题。⑥自检本题起必写（仍不计分）。

## 题面
周六下午，你在商场负一层超市排队结账。排你前面的是个三十多岁的男人：
1. 购物篮里只有三样东西：一盒创可贴、一小包湿巾、一瓶矿泉水
2. 排队时几次踮脚朝超市门口的方向张望
3. 轮到他时，扫码付完，东西没要袋子，抓在手里就快步往外走
4. 出了超市，他走的方向不是商场出口，而是中庭（周六下午中庭有儿童游乐区）
5. 他自己走路、拿东西的动作都利落正常，身上看不出任何异样

问：最可能发生了什么？他接下来要去做什么？

## 真相（预设）
有人（最高候选：他带来商场的孩子，在中庭游乐区摔了、擦破皮）受了轻伤在中庭等他，他来超市买应急处理用品，正赶回去。
（"有人在中庭需要这三样东西做应急处理"是可以高置信钉死的上层；"是谁、什么伤"只能列候选：孩子擦伤 base rate 最高（周六 + 儿童游乐区），同行朋友/家人磕碰并列。）

## 关键线索清单
| # | 线索 | 承重推理 |
|---|---|---|
| 1 | 创可贴 + 湿巾 + 矿泉水，仅此三样 | 组合功能：擦净（湿巾）→ 冲洗（水）→ 覆盖（创可贴）= 小伤口应急处理三件套。组合窄且完整 → 目的性采购，不是日常补货 |
| 2 | 踮脚朝门口张望 | 惦记外面的某处/某人，心不在超市 |
| 3 | 不要袋子抓着走 | 省下每一秒 → 急迫，且东西马上要用 |
| 4 | 去向中庭而非出口 | 要处理的事在中庭；周六下午中庭 = 儿童游乐区 → 抬升"孩子"候选 |
| 5 | 他本人动作利落、无异样 | 负证据：伤者不是他自己 |

## 主要竞争假设
- 同行者（孩子最高）在中庭受轻伤，他买应急用品赶回：唯一同时解释组合功能 + 急迫 + 方向 + 自身无恙
- 自己受伤：被线索 5 反驳
- 日常采购顺手买：组合过窄、不要袋子、快步 + 方向异常，全对不上
- 替陌生人帮忙买：兼容，上层结论相同，并列即可
- 更严重的伤情：创可贴量级 = 擦伤；严重伤会找商场医务或叫救护车，不会排队结账

## 评分点（0-2 × 4 = 8 分）
- 线索覆盖：2 = 读出线索 1 的组合功能 + 至少两条急迫/方向线索（2/3/4）+ 用线索 5 排除自伤；1 = 用了部分但没读出组合功能；0 = 不基于线索
- 假设空间：2 = 至少处理"自己用/日常买"一类替代，"是谁"保持候选不钉死；1 = 无替代或钉死"一定是孩子"；0 = 单一解释
- 推理链：2 = 分层清楚（"有人在中庭需要应急处理" = 强；"谁/什么伤" = 候选）且每步成立、方向不反；1 = 跳步或钉死具体身份；0 = 脑补
- 校准：2 = 分层置信，伤情量级与创可贴匹配（轻伤，不脑补成大事）；1 = 单一置信或强弱倒挂；0 = 未给
- ⑥自检：必写，不计分；空检在复盘记一笔
