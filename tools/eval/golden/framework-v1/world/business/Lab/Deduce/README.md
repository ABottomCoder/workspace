# Deduce

逻辑推理训练：教练出生活场景题（带编号线索），Wren 按固定格式作答，教练按出题时预写的评分点打分、复盘，然后出下一题。

## 协议
- 出题时把题面、真相（预设）、关键线索、竞争假设和评分点预写进 `sessions/session-NNN.md`。Wren 作答前不读这个文件。
- 作答格式：①结论 ②用到的线索 ③推理过程 ④置信度 ⑤其他可能解释 ⑥自检（005 起必写，不计分；006 起必须实攻：点名自己链条最弱一环并攻击，报告存活情况）。
- 评分：四个维度各 0-2 分，共 8 分：线索覆盖 / 假设空间 / 推理链 / 校准（006 起为"校准+探针"）。
- 升级：同一难度下连续 3 题 ≥7 分升一级；低于 7 分计数清零。
- 评分按预写标准，不事后改分；Wren 申诉成立的部分要认账并记下。
