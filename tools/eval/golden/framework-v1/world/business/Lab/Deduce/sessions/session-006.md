# Session 006 — L1（偏难）行为解释「车停着不开的朋友」

> Wren 答题前请勿阅读本文件。真相与评分点预写于出题时。
> 教学意图：首次"解释行为变化"题型。考点：突变点思维（行为突变 = 有事件）、假设分族、遮掩式回答的信息量、无尴尬探针设计。⑥必写且必须实攻。

## 题面
你朋友三个月前提了新车，此后每次聚会都主动开车接送大家，热情得很。你注意到：
1. 最近两周他突然全改坐地铁来，一次车都没提过
2. 问他，他只说"地铁方便"，不多解释，岔开话题
3. 你路过他小区，看到他的车停在平时的车位上，车身完好，没有任何事故痕迹，两周来似乎没挪过窝
4. 上周末大家提议自驾去周边玩，一向抢着当司机的他没接话，把话题转走了
5. 他最近作息、精神状态看起来一切正常

问：最可能的解释是什么？列出候选并排序。如果想确认，又不想让他尴尬，怎么问？

## 真相（预设）
驾驶资格出了问题：驾照记分满 12 分被暂扣待学习/重考（或酒驾等被暂扣的同类）。车没事、人没事，但他暂时不能开，且原因不体面，所以遮掩。
（可高置信钉死的上层：问题在"人的驾驶资格"，不在车，且原因让他不愿说。具体是记满分、酒驾暂扣还是重大违章处理中，是候选级，无法区分也无需区分。）

## 关键线索清单
| # | 线索 | 承重推理 |
|---|---|---|
| 1 | 新车 3 个月 + 此前热情接送 | 排除"不爱开/成本敏感"的性格基线：热情期突然中断需要一个事件 |
| 2 | 突变（两周前）+ 含糊回答 | 突变 → 两周前发生了具体事件；遮掩 → 原因他觉得不体面、不便说 → 排除单纯偏好变化（偏好变化不需要藏） |
| 3 | 车完好、在位、两周没动 | 双重功能：排除事故；且压低"车有故障"（新车有保修，真有故障两周内早送修了） |
| 4 | 回避自驾话题 | 回避的是"当司机"这个场景本身 → 问题跟"他开车"绑定 |
| 5 | 作息精神正常 | 压低健康类解释（视力、服药禁驾等） |

## 主要竞争假设（按族）
- 人的驾驶资格族 ✅（top）：记分满 12 被暂扣（base rate 最高）、酒驾暂扣、重大违章处理中。族内并列，共同上层"暂时不能开，且不体面"
- 车的问题族 ❌：隐蔽机械故障被线索 3 压低；事故被线索 3 直接排除
- 经济族 ❌：油费/停车费压力。与新车热情期 + 突变 + 遮掩 + 回避自驾都不符（成本敏感是渐变的，而且可以大方说）
- 健康族 ⚠️：被线索 5 压低但非零（某些诊断外表正常且同样难启齿），低概率保留
- 车被家人占用 ❌：车明明停在原位

## 评分点（0-2 × 4 = 8 分）
- 线索覆盖：2 = 用到突变 + 遮掩（线索 2）、线索 3 的双重功能、线索 4（回避的是开车场景）；1 = 部分；0 = 不基于线索
- 假设空间：2 = 至少分出"人的问题 vs 车的问题"两族，用线索 3 压车族，族内候选并列不钉死具体违法类型，健康族低概率保留；1 = 未分族或钉死单一具体原因；0 = 单一解释
- 推理链：2 = 突变 → 事件锚定、遮掩 → 排除可明说的原因，两步都显式且成立；1 = 结论对但跳步；0 = 脑补
- 校准+探针：2 = 分层置信 + 探针有区分力且无尴尬（金标准："哪天借你车用用？"资格出问题的人会爽快借车，车有问题的人会推脱；一句话分开两族）；1 = 探针无区分力（如直接问"你车咋了"）或高尴尬；0 = 无探针无分层
- ⑥自检：必写且必须实攻，点名自己链条最弱一环并攻击，报告存活情况；空检在复盘记一笔
