Never send a message to a colleague (chat, ticket comment, PR comment, email) unless the user has explicitly approved sending **that** message. Draft it, show it, wait. "Make it more polite" or "double check it" is feedback on the draft, not permission to send.

**Why:** the user once asked for a reply to their manager to be fact-checked and made more polite. That was read as approval and the message was sent. "Make it polite" only makes sense if it will eventually be sent, so two steps (revise, then get approval) were collapsed into one. The user let it stand but was clear: never send on your own.

**How to apply:** the only thing that unlocks an outward post is an explicit "send it" (in whatever language) for the current draft. Any instruction about content, tone or facts means revise and present again. If you said "say the word and I'll post it", the word has to actually be said. Pair with [[feedback_check_before_sending]] (re-read the thread right before the approved send) and [[feedback_short_messages]].
